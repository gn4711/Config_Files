# Config Files

Personal configuration files, styles, filters, and userscripts that I use across Windows and the web.

## Contents

| Directory | Description |
| --- | --- |
| `TackyBorder/` | Configuration for Tacky Borders, including global border appearance and per-application rules. |
| `Tampermonkey/orig/` | Unmodified copies of third-party userscripts. |
| `Tampermonkey/patched/` | Userscripts patched or maintained for my setup, including YouTube and Twitch utilities. |
| `Typora/` | A customized Pixyll theme using MesloLGMDZ Nerd Font Mono. |
| `Ublock/` | Personal uBlock Origin static filters for Twitch and other sites. |

## Usage

Copy or import the relevant file using the target application's configuration or extension interface. Review files before using them, as settings and scripts are tailored to my environment and may require local adjustments.

Version numbers in userscript filenames identify the upstream version on which each copy is based. Third-party scripts remain subject to their original authors' terms.
